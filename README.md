# Michael Chen's portfolio

A static, hand-built portfolio: plain HTML, CSS, and vanilla JS. No build step.

- `index.html`: all sections (hero, projects, journey, about, contact)
- `css/style.css`: styles and the day/dusk palettes (CSS variables at the top)
- `js/main.js`: theme toggle, project filters, copy-email, rider easter egg

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx live-server . --port=5500
```

`live-server` reloads the browser whenever a file changes.

## Deploy

Hosted with GitHub Pages from the `mwc2150.github.io` repo (Settings → Pages → deploy from `main`, root).
